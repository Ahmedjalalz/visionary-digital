# 📦 Design Package for Graphic Designer

Welcome! This folder contains all the official brand identity assets, color specifications, and typography hierarchy for **Education And Life Foundation (EFL)**.

## 🚀 Quick Start — What to Look at First:

1. **`ELF_Brand_Style_Guide.png`**
   - A single, high-resolution (300 DPI style) visual specification poster.
   - Shows all 10 color swatches with **HEX, RGB, and Print CMYK**, plus the three-typeface typography specimen cards, exact font scale matrix, and UI button elements.

2. **`ELF_Brand_Style_Guide.html`**
   - Double-click to open in any web browser (Chrome, Edge, Safari, Firefox).
   - Fully interactive and formatted for print: press **`Ctrl + P`** (or **`Cmd + P`** on Mac) to print or save directly as a clean PDF brand sheet!

3. **`BRAND_STYLE_GUIDE.md`**
   - The complete markdown documentation containing copy-pasteable color codes, CSS formulas, WCAG contrast ratings, and typography scale tables.

4. **`assets/`**
   - High-resolution transparent PNG logos:
     - `efl-logo.png` — Official Foundation logo
     - `emblem.png` — Official circular emblem
     - `school-in-a-bag-logo-blue.png` — School-in-a-Bag primary edition
     - `school-in-a-bag-logo-red.png` — School-in-a-Bag red alert edition
     - `brand_concept_mockup.jpg` — Presentation board concept
