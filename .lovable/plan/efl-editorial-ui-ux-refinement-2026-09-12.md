# EFL Editorial UI/UX Refinement

## Goal
Refine the existing site into a crisp, premium, photography-led nonprofit experience without changing routes, forms, data flows, or working features. Keep the current Foundation Blue palette and the existing Bricolage Grotesque, Instrument Sans, and Instrument Serif typography.

## Visual direction
- Apply the selected restrained editorial-minimalist direction through composition, image scale, hierarchy, and spacing—not new colors or fonts.
- Keep backgrounds clean white and cool pale blue-gray; remove any remaining warm-paper feel.
- Use varied magazine-style pacing: full-bleed photography, asymmetric editorial splits, quieter text-led passages, and selective structured lists.
- Reduce decorative badges, glass panels, repeated cards, heavy overlays, excessive uppercase text, and unnecessary motion.

## Homepage
- Rebuild the existing hero composition around the exact message “Uplifting the Lives of Community,” a single supporting statement, and restrained actions.
- Preserve the child’s face through art-directed cropping and place text only in safe negative space.
- Give the hero substantial responsive height and reveal a visual hint of the next section.
- Re-sequence existing sections into a clearer visual story: purpose, projects, impact, human story, mission, support, and location/footer.
- Replace the long uniform project rail with a more deliberate editorial showcase using varied image weights while retaining links to every project.

## Project listing
- Replace the identical card grid with a lead project and a varied magazine grid for the remaining projects.
- Keep the existing filters and project order.
- Use restrained hover scaling, title/arrow movement, consistent image quality, and intentional aspect ratios.

## Project detail pages
- Introduce multiple hero compositions selected from each project’s existing layout type: full-bleed, split editorial, or centered image-led.
- Increase desktop hero presence to roughly 65–85vh while keeping mobile heights natural and unclipped.
- Extend project image data with art-direction values such as hero position and gallery positions.
- Rework problem, response, outcomes, gallery, project-specific tools, closing support, and related-project sections into varied editorial compositions without changing their content or behavior.
- Avoid using the same hero image again for the closing section when a relevant gallery image exists.

## Imagery
- Audit every project’s hero and gallery against its subject and use the best existing official/local photography first.
- Avoid unrelated imagery and repeated generic photos across different causes.
- Apply per-image crop positions to preserve faces, equipment, water infrastructure, classroom activity, and other key subjects.
- Add clear neutral image slots only where no relevant image exists; no random filler imagery.

## Supporting pages and shared system
- Standardize section spacing and responsive rhythm across About, Impact, News, Contact, Booking, Donation, bag tracking, and shared site elements.
- Refine the most repetitive card-heavy areas into editorial lists, image/text compositions, and full-width visual moments while preserving controls and forms.
- Keep the official navigation, logo, donation priority, booking flow, maps, school coverage, tracking experience, footer, and database behavior intact.
- Remove any remaining fixed programme-count wording.

## Verification
- Check every content route for required unique metadata.
- Validate builds and browser behavior with no console/runtime errors.
- Review homepage, project listing, representative project layouts, forms, and shared navigation/footer at desktop and mobile widths.
- Confirm imagery loads locally, important subjects are not cropped, text does not overlap faces, and reduced-motion behavior remains supported.
